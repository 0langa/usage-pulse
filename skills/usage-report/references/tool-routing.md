# Usage Pulse Tool Routing

Use this reference only when the report request is ambiguous.

| User wording | Tool |
| --- | --- |
| today, so far, daily status | `pulse.today` |
| current session, this chat | `pulse.session` |
| since Monday, this week, date range | `pulse.range` |
| top tools, most used MCP, busiest project | `pulse.top` |
| compare, versus, up or down | `pulse.compare` |
| export, dump, CSV, JSON | `pulse.export` |
