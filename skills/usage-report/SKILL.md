# Usage Report

Pick one MCP tool:

- Today/current session: `pulse.today` or `pulse.session`.
- Date/window report: `pulse.range`.
- Most-used tools/projects/agents: `pulse.top`.
- Trend comparison: `pulse.compare`.

Format `summary` first, then the smallest useful table. Do not infer dollar cost. Token counts are estimates only.
